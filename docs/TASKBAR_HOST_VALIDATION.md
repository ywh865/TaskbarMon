# 任务栏宿主验证

TaskbarMon 只在识别到明确的 Explorer 层级时尝试嵌入。经典模式会保存任务列表与
自身窗口的父窗口、样式、扩展样式、屏幕像素位置和尺寸；Windows 11 覆盖模式不会
调整任何 Explorer 子窗口。任何布局识别、附加、调整或恢复失败都会回退为浮动条，或
取消正常退出并重试恢复。

当前仓库的静态检查不能代替真实 Explorer 验收。发布前必须在目标版本实际执行以下
场景，并保留截图和日志：

1. Windows 10 水平与垂直任务栏：附加、调整宽高、关闭、再次启动；确认任务列表完全恢复。
2. Windows 11 主任务栏：覆盖显示、关闭、Explorer 重启后重新创建；确认未改变开始按钮、通知区域或任务列表的尺寸。
3. 不支持的布局、辅助显示器和 Wine：确认只显示浮动条，且没有 Explorer 窗口被重设父窗口或缩放。
4. 在附加状态关闭应用、注销/关机、采样线程延迟退出和恢复失败：确认应用取消退出并持续重试，而不是留下被缩放的 Explorer 窗口。

在这些场景完成前，不得把“嵌入模式已验证”作为发布结论。
